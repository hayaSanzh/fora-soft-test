  - [x] 4.7 `rateLimiter`: token bucket на сокет для чата (burst 5, refill 1/с → `RATE_LIMITED`) и лимит 100 `signal:*` / 10 с с отключением сокета. (0.5 д)

    - Результат: `TokenBucket` (burst 5 + 1/с, ответ `RATE_LIMITED` **без разрыва** сокета) и `SlidingWindowCounter` (100 `signal:*` / 10 с → отключение сокета). Окно скользящее: 2 × limit на стыке окон не проходят.

      - **E13 проверяет раскладку по фактическим координатам плиток**, а не по CSS-классу: две различные координаты по X и две по Y — это и есть 2×2. Плюс отсутствие горизонтальной прокрутки при 1024px.
